### Investigation and Endpoint Verification
- **Provider documentation & endpoint**: Global Fishing Watch API v3 endpoint for vessel tracks is `GET https://gateway.api.globalfishingwatch.org/v3/vessels/{vesselId}/tracks` ([documentation](https://globalfishingwatch.org/our-apis/documentation/)).
- **Query parameter requirement**: The endpoint requires a dataset parameter conforming to `tracks:*` type (`datasets[0]=...`). Without it or with non-track datasets, the API returns HTTP 422: `{"statusCode":422,"error":"Unprocessable Entity","messages":[{"title":"The","detail":"The dataset should be a tracks:* type. Invalid: [...]"}]}`.
- **Access check on known Gulf of Mannar vessel**:
  - Queried a known regional fishing vessel identified from the verified Gulf of Mannar events dataset (`ac2ecad8c-c16a-840d-d6d3-c3f624ebeb95`).
  - Tested dataset candidates: `public-global-all-tracks:latest`, `public-global-all-tracks:v3.0`.
  - Provider response: `HTTP 403 Forbidden`
  - Exact body received: `{"statusCode":403,"error":"Forbidden","messages":[{"title":"Forbidden","detail":"Forbidden. You don not have permission to access this dataset [public-global-all-tracks:latest]","metadata":{}}]}`.
- **Provider rate-limit headers observed**:
