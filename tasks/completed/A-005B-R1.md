## Concrete defect

A report selecting a 48-hour historical window accepted an assessment with lookback_hours=168 in Codex's in-memory reproduction. The hash remained valid. reports.create_report selects the assessment by ID and MMSI but does not verify its observation window. Assessments retain a stable ID across syncs and do not store start/end anchors; resending the same client bounds cannot prevent another sync from replacing that row with a different window. Matching only the number of hours is insufficient.

### Storage decision and migration

`vessel_assessments` previously stored only `lookback_hours`, which cannot distinguish two windows of equal duration. No existing field or table held exact anchors, so additive migration `apps/api/alembic/versions/013_assessment_window.py` adds nullable `window_mode`, `window_start` and `window_end` columns plus checks for the allowed mode and paired anchors. The stable `(mmsi, rule_version, source_mode)` identity is unchanged; a re-sync updates the same row's anchors, which is exactly what the report check must detect. Legacy rows remain `NULL` and are returned as `window: null`; anchors are never inferred from duration or `evaluated_at`. The migration was applied to the shared development database (`alembic upgrade head`, now revision `013`); no reset, seed or data rewrite was performed.

### Changed paths

- `apps/api/alembic/versions/013_assessment_window.py` — nullable window mode/anchors and safe checks.
- `apps/api/app/services/fleet.py` — `window_payload(...)` formats stored anchors without inference and marks partial rows as `anchors: "missing"`.
- `apps/api/app/api/assessments.py` — sync persists `window_mode`/`window_start`/`window_end` (insert and conflict update); list selects and returns the additive `window` object.
- `apps/api/app/api/reports.py` — resolves the actual report window, fetches persisted anchors, rejects historical mismatches/legacy rows with `409` before SAR/weather/report insertion, and hashes both the report window and the persisted assessment window.
