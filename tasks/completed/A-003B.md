## Goal and context

User B's unmerged remote branch `origin/b/sprint` calls `GET /api/v1/environment/regional` and expects a JSON object with `variable`, `value`, `unit`, `observed_at` and `attribution`. Their formatter uses only those fields. Our API already serves the local historical Copernicus subset through `apps/api/app/api/ocean.py::load_satellite_observations`; no `/environment/regional` route exists. This task is independent of the blocked GFW track access (`tasks/blocked/A-003A.md`).
